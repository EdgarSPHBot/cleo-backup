## Cadence outage + restore (with David) <!-- project: github.com/CleoSPHBot/cleo-workspace -->

- David reported Cadence down 07:20 UTC. Confirmed: nothing on :8765, pm2 daemon not running (no reboot; host up 50d).
- Cause: ~/.pm2/pm2.log shows a new pm2 daemon started 2026-09-29 00:53:12 (during the OpenClaw 2026.9.6 upgrade window), started cadence, then was "killed by signal" the same second. It was launched from a short-lived shell; when that shell exited, its process group (pm2 + cadence) got killed. No pm2 systemd unit exists, so nothing brought it back. Down ~30h (00:53 Sep 29 -> 07:22 Sep 30).
- pm2 lives under node v25.8.1 (/home2/cleo/.nvm/versions/node/v25.8.1/bin/pm2), NOT on the default v24.21.0 PATH -> "pm2: command not found" in agent shells.
- Fix: `setsid nohup pm2 resurrect` (detached from the shell). Verified online after the shell exited, :8765 listening, local/Tailscale/index-v2 all 200, Mongo + change streams connected, error log empty. No code/data changes.
- Lesson: always start pm2 detached (setsid) from agent exec shells. Durable fix = `pm2 startup` systemd unit (needs sudo) -> pending David.
